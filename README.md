# Многомерный статистический анализ социально-экономических показателей регионов

Данный проект выполнен в рамках курса по многомерному статистическому анализу.  
**Цель исследования:** с помощью методов снижения размерности, кластеризации и регрессии выявить основные факторы, влияющие на целевой показатель регионов России, и сгруппировать регионы по схожим характеристикам.

---

## 📊 Данные

| Код | Показатель |
|-----|------------|
| **X1** | Численность населения с доходами ниже прожиточного минимума (%) |
| **X2** | Среднедушевые доходы населения (в месяц), руб. |
| **X3** | Потребительские расходы в среднем на душу населения (в месяц), руб. |
| **X4** | Смертность населения трудоспособного возраста (на 100 000 человек) |
| **X5** | Заболеваемость на 1000 человек населения |
| **X6** | Численность населения на одну больничную койку |
| **X7** | Выбросы загрязняющих веществ в атмосферный воздух (на 10 000 человек, тыс. тонн) |
| **X8** | Использование свежей воды (на 10 000 человек, млн м³) |
| **X9** | Сброс загрязненных сточных вод (на 10 000 человек, млн м³) |

## 🧪 Методы анализа

### 1. Факторный анализ (PCA)
- Проверена значимость корреляционной матрицы (χ² = 324.5, p < 0.001).
- Выделены **3 главные компоненты**, объясняющие **67.4%** общей дисперсии.
- Матрица нагрузок позволила интерпретировать компоненты как обобщённые факторы экономической активности.
  ### 1.2. Собственные значения и доля объяснённой дисперсии
| Компонента | Собственное значение | % дисперсии | Накопленный % |
|------------|----------------------|-------------|---------------|
| PC1        | 3.279                 | 36.44%      | 36.44%        |
| PC2        | 1.702                 | 18.92%      | 55.36%        |
| PC3        | 1.083                 | 12.03%      | 67.39%        |
| PC4        | 0.966                 | 10.74%      | 78.13%        |
| PC5        | 0.851                 | 9.45%       | 87.58%        |
| PC6        | 0.440                 | 4.89%       | 92.47%        |
| PC7        | 0.324                 | 3.60%       | 96.07%        |
| PC8        | 0.251                 | 2.78%       | 98.85%        |
| PC9        | 0.103                 | 1.15%       | 100.00%       |

- **Критерий Кайзера** рекомендует оставить 3 компоненты (λ > 1).
- Три компоненты объясняют **67.4%** общей дисперсии.

### 2. Кластерный анализ
- Применены **иерархическая кластеризация (метод Уорда)** и **K‑средних**.
- Оптимальное число кластеров – **7** (по критерию «локтя» и содержательной интерпретации).
- Выделены группы регионов: высокоразвитые (Москва, ХМАО, Татарстан), сырьевые северные, сельскохозяйственные центральные, депрессивные (Северный Кавказ) и др.

### 3. Регрессионный анализ (OLS)
-Построена множественная линейная регрессия для объяснения целевой переменной Y через исходные факторы X1–X8.
**Качество модели:**
- R² = 0.383, скорректированный R² = 0.318
- F-статистика = 5.902, p = 7.22e-06 (модель значима)
- Durbin-Watson = 1.775 (нет автокорреляции).
  
**Коэффициенты регрессии:**
| Переменная | Коэффициент | Стандартная ошибка | t-статистика | p-значение |
|------------|-------------|-------------------|--------------|------------|
| const      | 0.000       | 0.090             | 0.000        | 1.000      |
| X1         | 0.063       | 0.123             | 0.507        | 0.614      |

## 📈 Результаты

- **PCA** позволил сократить размерность с 8 до 3 факторов без существенной потери информации.
- **Кластеризация** выявила чёткие группы регионов, что может быть использовано для региональной политики.
- **Регрессионная модель** показала, что основными драйверами целевого показателя являются факторы X3, X5 и X8, а фактор X2 действует угнетающе.
