# Многомерный статистический анализ социально-экономических показателей регионов

**Цель исследования:** с помощью методов снижения размерности, кластеризации и регрессии выявить основные факторы, влияющие на целевой показатель регионов России, и сгруппировать регионы по схожим характеристикам.

### 2. Кластерный анализ
- Применены **иерархическая кластеризация (метод Уорда)** и **K‑средних**.

#### 2.1. Метод Уорда (иерархическая кластеризация)
```python
def ward_clustering(n_clusters):
    clusters_ward = fcluster(Z, n_clusters, criterion='maxclust')
    result[f'Кластер_Уорд_{n_clusters}'] = clusters_ward
    for cluster_num in range(1, n_clusters + 1):
        cluster_regions = result[result[f'Кластер_Уорд_{n_clusters}'] == cluster_num].index.tolist()
        print(f"\nКластер {cluster_num} ({len(cluster_regions)} регионов):")
        print(", ".join(cluster_regions))
    return clusters_ward
n_clusters_list = [7]
for n_clusters in n_clusters_list:
    ward_clustering(n_clusters)
```
При пороговом значении ρ = 10.45 все регионы РФ разбиваются на **7 кластеров**. КАРТИНКА

#### 2.2. Метод K-средних
```python
from sklearn.cluster import KMeans
def elbow_method(data, max_k=10):
    wcss = []  # Within-Cluster Sum of Square
    for k in range(1, max_k + 1):
        kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
        kmeans.fit(data)
        wcss.append(kmeans.inertia_)
    return wcss
max_k = min(10, len(result) - 1)
wcss = elbow_method(result, max_k)
kmeans_7 = KMeans(n_clusters=7, random_state=42, n_init=10)
kmeans_labels_7 = kmeans_7.fit_predict(result)
result['Кластер_Kmeans_7'] = kmeans_labels_7 + 1  # +1 чтобы кластеры начинались с 1
for cluster_num in range(1, 8):
    cluster_regions = result[result['Кластер_Kmeans_7'] == cluster_num].index.tolist()
    print(f"\nКластер {cluster_num} ({len(cluster_regions)} регионов):")
    print(", ".join(cluster_regions))
```
Методом K-средних все субъекты РФ разбиваются на **7 кластеров**. КАРТИНКА

## Результаты
- **PCA** позволил сократить размерность с 8 до 3 факторов без существенной потери информации.
- **Кластеризация** выявила четкие группы регионов, что может быть использовано для региональной политики.
- **Регрессионная модель** показала, что основными драйверами целевого показателя являются факторы X3, X5 и X8, а фактор X2 действует угнетающе.
